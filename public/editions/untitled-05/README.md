# Untitled 05, Edition 05

Drop the 5 product photos for **Untitled 05** into this folder, named:

```
01.jpg   <- cover (used on the catalogue grid)
02.jpg
03.jpg
04.jpg
05.jpg
```

Then enable them in `lib/editions.ts` by setting:

```ts
images: [
  "/editions/untitled-05/01.jpg",
  "/editions/untitled-05/02.jpg",
  "/editions/untitled-05/03.jpg",
  "/editions/untitled-05/04.jpg",
  "/editions/untitled-05/05.jpg",
],
```

See `public/editions/README.md` for format guidance.
